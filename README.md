# ไทย Reader（泰文閱讀）

在 iPad 上讀泰文的 App（PWA）：開 PDF 或貼上文字，點一下就查詞，有中文詞義、句型說明、朗讀、整篇翻譯，還能畫螢光筆、手寫、加文字框，並把生字存成生字卡複習。

## 怎麼安裝到 iPad

1. 用 Safari 打開這個 App 的網址。
2. 點分享按鈕，選「加入主畫面」。
3. 主畫面會出現「ไทย Reader」的圖示，之後點它打開，沒網路也能用。

## 資料存在哪裡

PDF、筆記、生字卡都只存在你自己的裝置上，不會上傳。換裝置時請用「設定 → 備份與還原」。
